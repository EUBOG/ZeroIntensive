# ВайбКод — лендинг курса

Одностраничный сайт курса по вайб-кодингу с Claude Code: создавайте сайты и
простые сервисы по текстовому описанию, без единой строчки кода. Аудитория —
новички, дизайнеры и маркетологи.

Статика без сборки и зависимостей: открыли `index.html` — работает.

## Что внутри

| Файл | Назначение |
| --- | --- |
| `index.html` | Разметка всех секций: hero, аудитория, принцип, навыки, программа, проекты, тарифы, наставники, отзывы, FAQ, форма, футер |
| `assets/css/style.css` | Тёмная градиентная тема, сетка, адаптив, анимации |
| `assets/js/main.js` | Интерактив: canvas-фон, scramble-текст, tilt-карточки, счётчики, форма |
| `assets/img/` | Скриншоты для превью в репозитории |

Итого около 95 КБ, три файла кода. Шрифты подключаются с Google Fonts,
остальное лежит внутри проекта.

## Запуск

Нужен любой локальный статический сервер — `file://` не даст нормально
отработать некоторым эффектам из-за политик безопасности браузера.

```bash
python -m http.server 8000
```

Затем откройте <http://localhost:8000>. Node не требуется, но подойдёт любой
аналог: `npx serve`, Live Server в VS Code, php -S.

## Деплой

Сайт полностью статический, поэтому GitHub Pages работает без настройки.

1. Запушьте репозиторий на GitHub.
2. `Settings` → `Pages` → `Source`: ветка `main`, папка `/ (root)`.
3. Сайт будет доступен по адресу `https://<user>.github.io/<repo>/`.

Подойдёт и любой другой хостинг: Netlify, Vercel, Cloudflare Pages — достаточно
перетащить папку, сборка не нужна.

## Форма заявок

Сейчас форма работает в демо-режиме: она проверяет заполнение обязательных полей
и честно сообщает, что данные никуда не отправились. Это сделано намеренно,
чтобы сайт не обещал отправку, которой нет.

Чтобы подключить реальный приём заявок, укажите адрес обработчика в начале
соответствующего блока:

```js
// assets/js/main.js
const LEAD_ENDPOINT = 'https://ваш-домен/api/lead';
```

На endpoint уходит `POST` с JSON из полей формы. Обработчик должен вернуть
статус 2xx — при ошибке пользователь увидит сообщение о неудачной отправке.
Если это форма Google Forms, Telegram-бот или CRM, проще всего написать
небольшой серверный обработчик и указать его URL.

## Структура и классы-хендлеры

Разметка опирается на дата-атрибуты, вся логика навешивается из JS:

| Атрибут | Что делает |
| --- | --- |
| `data-scramble` | Заголовок собирается из случайных символов и повторяет эффект каждые 9 секунд |
| `data-tilt` | Карточка слегка наклоняется за курсором (только на устройствах с мышью) |
| `data-magnet` | Кнопка притягивается к курсору |
| `data-count` | Число докручивается до значения при попадании в экран |
| `data-step` | Строка консоли в hero появляется с задержкой |

В hero консоль каждые 9 секунд собирает один из шести проектов: студия йоги,
сайт фотографа, квиз для маркетинга, калькулятор стоимости, магазин handmade
и бот для записи.

## Доступность

- Полное уважение `prefers-reduced-motion`: эффекты, циклы и счётчики
  отключаются, контент виден сразу.
- Интерактив работает и без JavaScript: в `index.html` есть проверка класса `js`,
  скрывающая анимационные состояния, а бегущая строка и списки остаются в разметке.
- Семантические теги, `aria-label` на иконочных кнопках, видимый фокус.
- Контраст текста соответствует WCAG AA.

## Адаптивность

Проверено на ширинах 1440, 1024, 768 и 390 пикселей — горизонтальной прокрутки
нет ни на одной. На мобильных шапка сворачивается в бургер-меню, анимации
консоли и tilt-эффекты отключаются.
